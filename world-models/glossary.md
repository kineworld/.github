# 世界模型术语表

[返回目录](README.md)

| 术语 | 简洁解释 | 小心混淆 |
| --- | --- | --- |
| Observation / 观察 | 传感器实际获得的信息 | 不等于完整真实状态 |
| State / 状态 | 足以描述演化所需的信息 | 一张图不必然充分 |
| Latent / 潜变量或隐表示 | 未直接观察、由模型表达的内部量 | 不天然对应物理概念 |
| Encoder / 编码器 | 将输入转换为表示 | 有用特征不等于动力学 |
| Decoder / 解码器 | 从表示产生可观察输出 | 并非所有世界模型都需要像素解码 |
| Dynamics / 动力学模型 | 预测状态如何变化 | 不是静态物体识别 |
| Action-conditioned / 动作条件 | 预测依赖给定动作 | 有文字输入不必然等于动作控制 |
| Rollout / 滚动展开 | 连续预测或执行多个时间步 | 开环预测不同于每步看真实状态 |
| Closed loop / 闭环 | 行动后用新观察更新决策 | 比一次性生成更接近控制评测 |
| MPC / 模型预测控制 | 规划一段，执行一步，再规划 | 计算预算影响结果 |
| Policy / 策略 | 根据输入选择动作 | 策略不是世界模型本身 |
| Reward / 奖励 | 任务希望优化的反馈 | 预测损失不等于任务奖励 |
| POMDP | 部分可观测决策问题的数学框架 | 不要求每次把完整分布显式存下来 |
| JEPA | 联合嵌入预测架构 | 不等于所有版本都能规划 |
| Stop-gradient | 阻止某条分支通过当前损失反传 | 单独使用不保证训练成功 |
| EMA | 参数指数移动平均 | 不是让目标永远不变 |
| Collapse / 坍塌 | 表示趋同、失去区分信息等退化 | loss很低也可能无用 |
| Diffusion / 扩散 | 通过学习去噪等过程生成样本的一类方法 | 不保证物理正确 |
| Flow matching / 流匹配 | 学习分布变换的向量场的训练方法 | 与所有扩散实现不能一概等同 |
| Calibration / 校准 | 概率预测与实际频率匹配程度 | 自报置信度不等于已校准 |
| OOD / 分布外 | 条件偏离训练分布 | 新文件不一定是新分布 |
| Ablation / 消融 | 移除或替换部分设计以检查作用 | 要同时控制预算等因素 |
| Leakage / 泄漏 | 测试答案等不应可用的信息进入训练或输入 | 同一视频相邻帧划分可带来风险 |
| Distillation / 蒸馏 | 从教师模型输出或表示学习学生模型 | 不自动产生新知识或获得使用许可 |
| Sim-to-real | 从模拟环境迁移到现实 | 模拟成功不等于现实安全 |
| 3DGS | 以三维高斯基元表示外观的路线 | 不自动具备碰撞与动力学 |
| GLB | glTF的二进制资产容器 | 文件格式不是世界模型算法 |
| SOTA | 某协议下的当前最佳水平 | 必须注明任务、版本、时间与证据 |
| Reproduction / 复现 | 按明确条件重建结果 | 不是把原作改名 |

遇到术语时做两件事：用一句自己的话解释，再举一个“看似符合但其实不够”的反例。
