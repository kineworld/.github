# 贡献与维护

[返回目录](README.md)

欢迎纠错、改进教学例子和补充可复现实验。不接受“读完必成世界第一”“未验证性能第一”之类承诺。

## 提交前

- 说明修改解决哪个学习问题，给出一手来源及核对日期。
- 保留作者归属；不要复制整篇论文、图片或上游代码而忽略许可。
- 新实验必须注明输入、预设知识、学习部分、指标与局限。
- 教学结果与公司研究成果分开；模拟数据不冒充用户数据。
- 不包含密钥、身份证、联系方式、私人公司材料或无授权数据。
- 检查相对链接；运行 `python world-models/labs/test_tiny_world.py`。
- 默认不要引入大下载、付费API或需要云算力的步骤。
