# 03 · 一张纸上的数学骨架

[目录](README.md) · 上一章：[基础](02-foundations.md) · 下一章：[路线](04-approaches.md)

符号先翻成人话：`o`是观察，`a`是动作，`z`是内部表征，`r`是奖励，`t`是时间。下标不是装饰，它决定模型有没有偷看未来。

## 从观察到预测

```text
z_t = Encoder(o_0, a_0, …, o_t)
p(z_(t+1) | z_t, a_t) = Dynamics(z_t, a_t)
可选：o_hat_(t+1) = Decoder(z_hat_(t+1))
```

编码器压缩历史。动力学模型预测变化。解码器将表征还原为可见内容，但并非所有路线都需要像素解码器。

部分可观测环境的理想对象是对隐藏状态的信念分布 `p(s_t | 历史)`；一个向量并不自动成为充分状态。若表示丢掉了未来决策需要的速度，预测器再大也可能补不回来。

## 预测损失与控制目标不同

最简单的平方误差：

```text
L_pred = 平均 ||预测未来 - 目标未来||²
```

像素、深度、潜在特征、速度都可作为目标，但单位和意义不同。两个不同编码器的潜在空间，通常不能直接比较原始MSE大小。

概率模型可最小化负对数似然 `-log p(真实未来 | 历史,动作)`；这奖励对实际发生结果赋予合理概率，不保证生成每个样本都漂亮。

控制目标则例如：

```text
选择动作序列，使 Σ[与目标的距离² + λ×动作大小²] 最小
```

更低的预测误差不必然带来更高控制成功率：模型可能精确预测背景，却预测错了碰撞瞬间。

## 一步与滚动多步

一步测试每次输入真实当前状态；开环多步测试反复输入模型自己的预测。若每步有偏差，多步会累积，而且规划器会主动走向训练数据少的地方。

所以要分别报告1步、5步、20步误差，而不是只公布最好的跨度。不同跨度最好使用同一批起点和真实动作序列。

## MPC：先想一段，只做一步

模型预测控制（MPC）的核心循环：

1. 从真实观察估计当前状态。
2. 在模型内评估候选动作序列。
3. 选择代价最低的序列，只执行第一个动作。
4. 得到新观察，再规划。

每步重新观察有助于纠偏，但模型严重错了仍会失败。候选数、规划长度和计算延迟也要计入成本。不能让一种方法搜索百万次，另一种只搜索一次，再把差异全归因于模型。

## JEPA示意损失

```text
context = Encoder(可见区域)
target  = stop_gradient(TargetEncoder(目标区域))
L = distance(Predictor(context, 目标位置), target)
```

这是教学示意，不是可直接替换某篇论文的实现。目标编码器更新、掩码、归一化、损失、时间上下文决定是否学到有用表示。`stop_gradient`表示这条目标分支不通过该损失反向传播；仅加这一行并不能保证避免表征坍塌。

若上下文已经包含被预测的未来像素，即使loss很好也可能泄漏。见[I-JEPA官方实现](https://github.com/facebookresearch/ijepa)与[V-JEPA官方实现](https://github.com/facebookresearch/vjepa2)，不要把通用示意误当成它们每个版本的精确公式。
