# KineWorld · 世界模型开放学习指南

**从看懂一个小球，到独立复现、评测和提出研究问题。**

中文主线 · 零基础入口 · 数学推导 · 开源路线 · 可运行实验 · 证据优先

这不是“读完即世界第一”的承诺。顶尖能力来自反复实现、做失败实验、接受同行复核与解决新问题。本指南的目标，是让你不再只会复述宣传语，而能判断一个系统究竟学到了什么、缺什么、如何验证。

版本：v0.1 · 整理与实验验证：2026-09-09 · 来源核对：2026-09-08。**这是一套入门到研究的路径，不是覆盖全部前沿的百科全书。** 随时间变化的模型、许可证和评测协议必须回到原始来源确认。

## 第一次来，怎么读？

1. 完全不懂AI：从[01 直觉](01-intuition.md)开始，先不碰大模型安装。
2. 会写Python：读[02 基础](02-foundations.md)后直接做[CPU小实验](labs/README.md)，再回来看理论。
3. 做过深度学习：从[03 数学](03-math.md)、[04 路线](04-approaches.md)和[07 评测](07-evaluation.md)进入。
4. 想做研究或创业：必须交出[10 毕业项目](10-research-roadmap.md)里的证据包，而不只是看完文章。

不设置“必须学90天”。按能力过关：能解释 → 能运行 → 能修改 → 能复现 → 能发现问题。会的部分直接跳过；不会的地方用实验补齐。

## 一句话框架

```text
观察与历史 → 状态表征 → 给定动作的未来预测 → 比较候选动作 → 行动
                 ↑                                   ↓
                 └────────── 用新观察纠错 ────────────┘
```

这是本教程偏重的**面向决策的世界模型**视角。领域中也有空间生成、交互视频等更宽用法，不能用一个定义抹掉它们，但比较时必须先说清任务。

## 学习原则

- 能输出漂亮画面，不等于能正确预测物理。
- 能预测下一步，不等于长时间稳定，也不等于能控制。
- 动作条件不是一句文字提示的同义词。
- 开源复现是正常研究；复现别人的结果不能改名声称原创。
- 本指南、教学实验与KineWorld公司的研究成果是不同类别。**教程实验不支持任何商业产品能力或排名声明。**

阅读顺序从[第一章](01-intuition.md)开始；已有基础直接[动手运行](labs/README.md)。原始资料集中于[来源地图](09-resources.md)。
