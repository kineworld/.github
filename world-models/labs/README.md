## 世界是什么？

小车状态为位置 `x` 与速度 `v`，动作 `a` 是推力控制量。真实模拟器用：

```text
下一步速度 = 0.9 × 当前速度 + 0.2 × 动作
下一步位置 = 当前位置 + 下一步速度
```

`0.9`是速度保留系数，数值越小阻尼越强。这是离散时间教学模型，不是带真实单位的车辆工程模型。

模型从40条随机轨迹的1000个转移样本，用最小二乘学习两个速度系数。**线性结构、状态变量、位置更新规则是我们预先提供的**，不是它从像素或毫无先验的数据中发现的。

## 输出怎么看？

- `learned`：学到的两个系数。在无噪声、结构正确的设置下通常非常接近真实值。
- `in_distribution.state_mse`：独立测试起点，在1/5/20步开环预测的状态均方误差。
- `one_step_persistence_mse`：假设下一步状态完全不变的简单基线；只用于一步比较。
- `shifted`：换测试阻尼，但不重新训练；观察原模型误差。
- `control_shifted`：相同起点上比较不行动、学习模型MPC和已知测试参数的oracle MPC。

状态MSE混合了本玩具系统的位置与速度数值，不是通用物理指标。控制代价为每步位置平方加速度平方惩罚和动作惩罚的累计；越低越好。成功要求30步后位置绝对值小于0.25且速度绝对值小于0.15；这个阈值只为教学而定。

MPC每次枚举 `3^4=81` 条四步动作序列，只执行第一步，再看真实状态重规划。oracle知道测试参数，但用同样短规划器，不代表最优控制。闭环观察可能纠正一部分错误，所以多步预测恶化不一定让控制同比例恶化。

## 三个实验

```bash
python world-models/labs/tiny_world.py --seed 42
python world-models/labs/tiny_world.py --test-damping 0.9
python world-models/labs/tiny_world.py --test-damping 0.2
```

先写预测，再运行：参数改变后，一步误差、20步误差、控制代价分别怎样变化？不要预设每种指标都严格单调。比较种子时保留所有结果，不选最好的一次。

进阶：为训练观察加入噪声；去掉动作项；只提供位置而不是速度；改变规划长度。每次只改一个变量并保留原版。若你改了模型结构，就不能继续把旧单元测试的参数恢复精度当作新模型正确性的证明。
