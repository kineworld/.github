# 勘境 · KineWorld

**合肥勘境智能科技有限公司**，是一家以 **通用世界模型** 为核心的研发公司。

我们的团队成员均在 **18岁左右**，致力于让机器学习环境如何变化，并利用预测开展规划与决策。

研究方向涵盖 **视觉与视频世界模型、动作条件世界模型、潜在动力学模型、生成式世界模型与多模态环境建模**。我们探索这些模型在工业摄像头、无人机和机器人等真实设备中的应用。以上为研发方向，具体能力与验证范围以对应项目证据为准。

**精选成果公开，核心实现闭源。**
