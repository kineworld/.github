## 1. PushT：确认的闭环成功率提升

姿态目标 CEM 成功 **33/50**，覆盖率目标 CEM 成功 **11/50**：增加 **44 个百分点**。配对胜出 24 场、失利 2 场；精确双侧 McNemar p = 0.00001049。配对成功率差的场景 bootstrap 95% 区间为 [+0.28, +0.60]。

两组使用相同预测器、传感器、20 步预测时域、每次决策 192 条模型 rollout 和最多 300 个执行步。主要比较在访问这批保留场景前本地冻结；不是外部预注册。平均峰值覆盖率为 0.94751 vs 0.76564。

见 **[完整成果说明](pusht-2026-10.md)** 和 **[50 对逐场景结果](pusht-paired-outcomes.csv)**。这项结果证明该指定模拟任务上的规划目标收益，不是跨模型、跨任务或机器人能力排名。

## 2. JEPA-WM：固定开发动作集合中的预测与排序优势

这里的 JEPA 对照是**官方预训练 PushT 编码器/预测器，加勘境本地训练的位姿读出头**，不是官方完整规划系统的复现。比较 64 个已经用于开发的上下文，每个上下文 8 个候选动作、5 步结果；归一化覆盖遗憾只在候选真实覆盖率差大于 0.01 的 17 个上下文计算。

| 方法 | 位置 RMSE（px）↓ | 角度 MAE（rad）↓ | 归一化覆盖遗憾 ↓ |
| --- | ---: | ---: | ---: |
| JEPA-WM + 本地任务头，seed 0 | 37.983 | 0.25035 | 0.17003 |
| JEPA-WM + 本地任务头，seed 1 | 39.275 | 0.28551 | 0.21272 |
| JEPA-WM + 本地任务头，seed 2 | 37.696 | 0.28840 | 0.17284 |
| 勘境物理先验方案，单次确定性拟合 | **1.364** | **0.00788** | **0.01404** |

相对于三个 JEPA 任务头指标的均值，位置 RMSE 降低 **96.44%**，归一化遗憾降低 **92.42%**。这是三种子指标的描述性汇总，不是三个独立物理模型的重复训练结果。

另一组附加微调的 JEPA 读出头位置 RMSE 为 35.997 / 35.942 / 38.359 px，遗憾为 0.20486 / 0.23334 / 0.21788，物理先验方案在这两项指标上也更低。

在全部 64 个上下文上，方案相对于三个原任务头的真实选中覆盖率均值提升分别为 **0.002024 / 0.002319 / 0.002178**。按 16 条整轨迹聚类、对六项比较调整后的区间分别为 [0.000380, 0.004838]、[0.000672, 0.004877]、[0.000691, 0.004535]。绝对覆盖率收益较小；不把较大的预测误差降幅替代成闭环成功率提升。

**条件：**物理方案额外使用已知 T 形几何、相机尺度与控制器先验；推理不输入真实未来状态。JEPA 有外部预训练，双方先验与计算不匹配。开发上下文已经看过，读出头使用开发位姿损失选检查点。因此可以报告**此固定动作集合上的具体优势**，不能写成“全面超越 JEPA”或“独立测试证明基础模型更强”。

公开 **[64 个配对上下文的选中覆盖率](jepa-paired-coverage.csv)**；实现与完整内部研究私有。

## 3. Physion++：V-JEPA 表征上的接触预测读出改进

三种方法使用同一冻结 **V-JEPA-2 ViT-L** 观察表征。勘境任务适配使用训练发布包的接触标签；属性辅助方案还使用物理属性训练监督，推理仍只接收观察特征。

| 方法 | AUROC ↑ | 准确率 ↑ |
| --- | ---: | ---: |
| 仅拟合集逻辑回归读出（C=1） | 0.56716 | 54.58% |
| 勘境接触任务适配，三种子集成 | **0.67512** | **62.15%** |
| 勘境属性辅助任务适配，三种子集成 | **0.67706** | **63.58%** |

属性辅助方案相对逻辑回归：AUROC **+0.10990**，按几何组配对 bootstrap 95% 区间 [0.08377, 0.13516]；准确率 **+9.00 个百分点**，区间 [+5.85, +11.93] 个百分点。接触任务适配相对逻辑回归：AUROC **+0.10796**、准确率 **+7.57 个百分点**，对应区间也均高于 0。

评估覆盖全部 **1,189 条样本 / 562 个几何组**，概率阈值 0.5。训练包经过几何隔离、观察截止前接触与重复 RGB 排除；采用额外训练监督。已发布测试集曾在更早实验中被查看，因此本项是固定模型的发布测试集复评，不是全新盲测；区间覆盖测试几何组，未覆盖训练种子或模型选择不确定性。属性辅助相对接触适配的额外增益很小，不另作显著提升声明。

这支持**在相同 V-JEPA 表征上改进特定接触任务读出**，不表示超过官方 V-JEPA 基础模型或白泽未知评测协议。

公开 **[全部 1,189 条匿名化标签与预测概率](physion-predictions.csv)**，可复算 AUROC 和准确率；不公开样本路径、编码器权重、训练代码或配方。

## 4. KineJing：特征预测误差降低 15.75%

| 方法 | 归一化特征 MSE ↓ |
| --- | ---: |
| 首帧保持 | 0.991879 |
| KineJing 动作条件预测 | **0.835667** |
| 同一模型的动作打乱诊断 | 0.895649 |

使用冻结 DINOv2 特征，按回合划分 80 训练 / 10 选择 / 10 评估，训练种子 20260920；最后一组一次评估，但整批公共开发样本此前已被探索。这个 **15.75%** 的降幅仅衡量特征预测，不代表 RGB 视频质量、官方 TriWorldBench 分数或跨任务泛化。没有多种子显著性声明；一次动作打乱是敏感性诊断，不是因果识别。

## 5. PushT：视觉前端与位置预测的保留测试优势

### 视觉前端

独立 50 个测试场景中，在同一冻结动力学下：

| 指标（px，均越低越好） | CNN 前端 | 颜色特征前端 |
| --- | ---: | ---: |
| 当前物体定位 RMSE | **26.603** | 37.022 |
| 一步物体位置预测 RMSE | **30.156** | 38.901 |
| 五步物体位置预测 RMSE | **50.244** | 53.919 |

一步位置误差降低 **22.48%**。前端用模拟器状态监督，适用于该 PushT 渲染器；这组预测优势不外推为闭环控制或通用视觉优势。

同一 CNN 感知下，动力学预测还低于保持当前估计位置的基线：一步 **30.156 vs 33.289 px**，五步 **50.244 vs 77.653 px**。

### 动作条件位置预测

另一组独立 50 个测试场景，输入真实模拟器状态：

| 方法 | 一步位置 RMSE（px）↓ | 五步位置 RMSE（px）↓ |
| --- | ---: | ---: |
| 静止基线 | 19.213 | 67.769 |
| 动作条件 Ridge | 15.780 | 44.056 |
| 勘境动作条件模型，seed 0 | **14.578** | **40.937** |
| seed 1 | **14.727** | **41.342** |
| seed 2 | **14.777** | **41.547** |

三个种子的一步位置 RMSE 相对 Ridge 的场景配对 95% 区间均低于 0。优势限定在位置预测；不作完整姿态或闭环性能声明。真实状态输入与收集策略使用物体位置，是该结果的重要条件。

### 视觉预测对保持基线

另一个 50 场景、渲染器专用视觉状态特征协议：一步位置 RMSE **38.231 vs 41.046**，五步 **51.686 vs 76.725**。对照保持当前视觉估计位置；此协议与上面的 CNN 测试不同，数字不跨表直接比较。这里只报告保存结果中的位置预测优势。

## 6. 几何结构：点目标任务上的保留测试优势

128 个保留构造状态、每状态 8 个动作及 4 个随机点目标：

| 方法 | 点目标归一化遗憾，seed 0 / 1 / 2 ↓ | 五步位置 RMSE（px），seed 0 / 1 / 2 ↓ |
| --- | --- | --- |
| 全局坐标 MSE 基线 | 0.10798 / 0.10245 / 0.11323 | 51.661 / 51.744 / 51.841 |
| 勘境实现的已知物体坐标系基线 | **0.02235 / 0.02088 / 0.02485** | **18.500 / 18.939 / 18.586** |

三种子的状态聚类遗憾差区间均低于 0。使用精确状态和零初始速度，是已有几何先验方法的工程对照，不声称原创算法。目标是点距离，**不是 PushT 的 T 形覆盖奖励**；没有 RGB 或闭环优势结论。

## 7. 规划器开发改进

在已经看过的同一 8 个开发场景上，固定模型和每次决策 rollout 预算：

| 比较 | 指标 | 改进方案 | 对照 | 证据说明 |
| --- | --- | ---: | ---: | --- |
| 姿态目标 vs 覆盖率目标 CEM | 平均峰值覆盖率 | **0.93293** | 0.72111 | 配对差 +0.21182，区间 [0.12826, 0.27928] |
| 加入历史精英记忆 vs 无记忆姿态目标 CEM | 平均峰值覆盖率 | **0.96704** | 0.93293 | 配对差 +0.03411，区间 [0.00662, 0.07692] |

前者成功计数 6/8 vs 1/8，后者 7/8 vs 6/8，但小样本成功率差未建立显著优越结论。上述区间仅描述重复使用开发场景的峰值覆盖率差；不是独立新场景确认。规划记忆来自已有 iCEM 类思路，不宣称新世界模型。

## 8. 其他数值较高的对照：不作已确认超越声明

同一 50 场景确认中，姿态目标 CEM **33/50（66%）**，原生 Diffusion Policy **25/50（50%）**。双方历史、物理先验与计算不同，协议也没有对这对方法设置主检验，因此只列计数，不能宣传为公平确认的 Diffusion Policy 优越性。

匹配的候选执行比较中，接触重排 **33/50**，首候选执行 **25/50**；配对成功率差 +16 个百分点。它是次要描述结果，平均峰值覆盖率差区间包含 0，不标为已确认的算法优势。完整 5 组计数保留在原冻结记录中。

## 9. 已知引擎参考：工程预测误差的进一步降低

在同一 64 个开发上下文、8 个候选、5 步预测中，已知完整模拟引擎的两种固定速度初始化，位置 RMSE 为 **0.941 / 0.957 px**，简化物理先验方案为 **1.364 px**。两组初始化均保留，不事后只选更好的一个。选中覆盖率的平均收益只有 0.00005169，不能把误差改进直接写成控制成功提升。

在全部 48 条已有训练轨迹、192 个上下文的 20 步预测中，均匀动作集合的位置 RMSE 从 **56.478** 降至 **30.379 / 29.036 px**；姿态 CEM 动作集合从 **35.059** 降至 **12.487 / 13.021 px**。它使用额外的准确引擎先验；这是旧数据上的工程参考，不是学习得到的新模型、独立测试或公平超越 JEPA 的证据。

## 核验与公开边界

**[机器可读指标与来源哈希](verified-metrics.json)** 保留三种子结果、指标口径、范围与源文件身份。Physion++ 的全部 1,189 条预测已独立复算；JEPA 比较的 64 对覆盖率及全部三个种子的均值增益已复算；样本数、区间方向和百分比已检查。本次整理没有重跑模型、重新选择检查点或公开训练实现。

结果来自勘境内部实验和审计，未经独立外部复现。完整源码、权重、配方、开发失败历史继续私有管理。没有可比协议的外部宣传数字、真实未来输入的 oracle 分数、合成机制探针、未完成训练及未通过预设门槛的候选，不作为“勘境超越”的公开成绩。

开源模型与任务贡献归属于原作者：[JEPA-WMs](https://github.com/facebookresearch/jepa-wms)、[V-JEPA 2](https://github.com/facebookresearch/vjepa2)、[DINOv2](https://github.com/facebookresearch/dinov2)、[Diffusion Policy](https://github.com/real-stanford/diffusion_policy) 及相关数据集作者。
